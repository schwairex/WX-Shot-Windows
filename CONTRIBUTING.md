# WX Shot'a katkıda bulunma

Katkınız için teşekkürler. Hata düzeltmeleri, performans iyileştirmeleri, erişilebilirlik çalışmaları ve iyi açıklanmış özellik önerileri memnuniyetle karşılanır.

## Geliştirme ortamı

Windows 10/11, Node.js 22 veya üzeri ve npm kullanın.

```powershell
npm ci
npm test
npm run check
npm start
```

## Değişiklik gönderme

1. Değişikliğin kapsamını küçük ve anlaşılır tutun.
2. İlgili testleri ekleyin veya güncelleyin.
3. `npm test` ve `npm run check` komutlarının geçtiğini doğrulayın.
4. Kullanıcı davranışı değişiyorsa README dosyasını güncelleyin.
5. Değişikliğin amacını ve elle yaptığınız kontrolleri pull request açıklamasında belirtin.

Lütfen güvenlik açıklarını herkese açık issue olarak paylaşmayın; bunun yerine `SECURITY.md` dosyasını izleyin.
