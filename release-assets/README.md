# Yayın dosyaları

Bu klasör, son kullanıcıya dağıtılacak kurulum paketini ve doğrulama dosyasını yerel olarak bir arada tutar.

`WX-Shot-Windows-Setup-1.2.0-x64.exe` dosyası büyük olduğu için normal GitHub deposuna commit edilmez. GitHub'da **Releases → Draft a new release → Assets** alanına yüklenmelidir.

Yükleme sırasında aynı klasördeki `WX-Shot-Windows-SHA256.txt` dosyasını da ekleyin. Böylece kullanıcılar indirdikleri paketin bütünlüğünü doğrulayabilir.
